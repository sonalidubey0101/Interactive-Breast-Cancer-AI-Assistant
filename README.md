# Interactive-Breast-Cancer-AI-Assistant
An interactive, explainable AI-powered clinical decision-support system for breast cancer screening. This project extends a breast cancer classification model into a comprehensive diagnostic assistant by integrating risk stratification, explainable AI (SHAP), batch patient screening, automated PDF report generation, and an analytics dashboard.

Key Features :-

AI-powered risk prediction with Low, Medium, and High risk stratification based on prediction probability.
SHAP explainability to visualize feature contributions for every individual prediction.
Batch screening through CSV upload for evaluating multiple patients simultaneously.
Automated PDF reports containing patient-specific screening results and model explanations.
Interactive Streamlit dashboard with screening analytics and intuitive visualizations.
Model performance dashboard displaying Accuracy, Precision, Recall, F1-Score, and ROC-AUC, with emphasis on Recall for healthcare screening applications.
Robust training pipeline featuring stratified train-test split, cross-validation, and hyperparameter tuning using GridSearchCV.
